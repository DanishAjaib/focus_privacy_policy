Privacy Policy — Focus for YouTube

Last updated: September 25, 2026

This extension does not collect, sell, or transmit any personal data to its developer or to any third party. Everything it stores stays within Chrome's own storage system, under your control.

What this extension stores, and where

Your settings (which distractions are hidden, thresholds, custom selector overrides) are stored using chrome.storage.sync — Chrome's built-in setting-sync mechanism, the same one Chrome uses to sync your bookmarks and preferences. This data is encrypted and synced by Google only across browsers where you are signed into the same Chrome/Google account. It is never sent to this extension's developer, and never to any server operated by this extension.

Your watch-time statistics (daily totals used to show your stats in the popup) are stored using chrome.storage.local, which stays only on the device it was recorded on. It is not synced, not backed up, and not transmitted anywhere. Uninstalling the extension deletes it permanently.

Both kinds of data can be cleared at any time from the extension's popup ("Reset selector overrides", "Reset session"), and watch-time data is only ever written by you actively using YouTube — never collected passively or in the background when YouTube isn't open.

What this extension does not do

  • No user accounts, sign-in, or identifiers of any kind
  • No advertising or ad networks
  • No analytics, telemetry, or crash reporting sent anywhere
  • No network requests made by the extension itself — the only outbound link is the "Support this extension" button in the popup, which opens PayPal's donation page in a new browser tab only if you click it

Permissions this extension requests, and why

  • storage — to save your settings (via Chrome sync) and watch-time stats (locally), as described above.
  • unlimitedStorage — watch-time history accumulates indefinitely rather than being capped or auto-deleted, so this permission avoids ever hitting a storage quota. It does not grant access to anything beyond what's described above.
  • Access to youtube.com — required for the extension to run its content script, which hides selected page elements and reads the current video's page state (e.g. whether it's playing, its URL) to decide what to hide. This access is scoped only to youtube.com and is not used to read or transmit page content anywhere.

Changes to this policy

If this policy changes, the "Last updated" date above will change accordingly. Material changes (e.g. if the extension ever started collecting data it doesn't today) would be described here plainly, not buried.
